## Startup Insights

- Value proposition: Your AI agent rebuilds any reference video as new footage in Google Flow and hands back a clean, watermark-free file.
- Problem solved: Google Flow has no official API or MCP, so creators recreate videos by hand: writing every prompt, generating clip by clip, downloading and cleaning each file. Content by Agent lets Claude Code or Codex do the whole job.
- Pricing model: One-time payment, no subscription: $49 for the first 10 buyers, $69 for the next 20, then $139.
- Target persona: AI video creators, faceless channel owners and developers using Claude Code or C
- Audience type: [B2C](https://trustmrr.com/search?targetAudience=B2C)
- Team size: 1 person
- Funding: Bootstrapped
- Estimated user count: 0
- Additional info: Content automation factory for Google Flow, which creators use instead of costly pay-per-clip AI video and image APIs. Works in Claude Code or Codex like a Higgsfield-style MCP: your agent generates every clip on its own, removes the watermark and delivers files into your session. One-time payment.
- Markets: [AI](https://trustmrr.com/category/ai), [Dev Tools](https://trustmrr.com/category/developer-tools), [Content Creation](https://trustmrr.com/category/content-creation)

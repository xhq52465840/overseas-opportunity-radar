## Startup Insights

- Value proposition: Screenshots every page of a website, desktop and mobile, in one run
- Problem solved: Cuts out screenshotting a site page by page, twice over, then renaming every file by hand
- Pricing model: Free for 200 pages a month, $49 one-time for unlimited (no subscription)
- Target persona: Web designers, developers, and agencies
- Audience type: [B2C](https://trustmrr.com/search?targetAudience=B2C)
- Estimated user count: 0
- Additional info: Mac app, signed and notarized by Apple. Runs entirely on your machine, so nothing is uploaded and no account is needed. Captures full-page at desktop and mobile, named from each URL, plus a Markdown export of page copy and a URL inventory.
- Markets: [Design Tools](https://trustmrr.com/category/design-tools), [Content Creation](https://trustmrr.com/category/content-creation), [SaaS](https://trustmrr.com/category/saas), [Utilities](https://trustmrr.com/category/utilities)

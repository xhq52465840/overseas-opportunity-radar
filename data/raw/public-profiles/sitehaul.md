## Startup Insights

- Value proposition: Screenshot every page of a website, desktop and mobile, in one run.
- Problem solved: Capturing a site by hand means a full-page screenshot of every page, again for mobile, then renaming every file. For a 40-page site that's 80 screenshots and an afternoon gone. SiteHaul reads the sitemap and captures every page at desktop and mobile size in one run, named from each URL.
- Pricing model: Free for 10 pages a month. $49 once for unlimited pages, page copy as Markdown, screen recording (beta) and mockups of every page. No subscription.
- Target persona: Web designers, developers, and agencies
- Audience type: [B2B](https://trustmrr.com/search?targetAudience=B2B)
- Team size: 1 person
- Estimated user count: 300
- Additional info: A signed, notarized Mac app (Apple silicon) that runs entirely on the user's machine: no uploads, no account, no server costs. It clears cookie banners and popups, handles staging sites behind logins, splits tall pages for Figma, and exports a URL list for redirect maps.
- Markets: [Design Tools](https://trustmrr.com/category/design-tools), [Content Creation](https://trustmrr.com/category/content-creation), [SaaS](https://trustmrr.com/category/saas), [Utilities](https://trustmrr.com/category/utilities)

## Startup Insights

- Value proposition: Auto-localizes React, Next.js, Vue and React Native apps — extracts hardcoded strings, generates keys, translates, and injects i18n code, then opens a PR.
- Problem solved: Adding i18n to an existing app means weeks of manually pulling strings out of components, wiring up libraries and managing translation files. Babelize does it in one run, and incremental runs only translate what changed.
- Pricing model: Free tier + paid credit-based plans (dashboard), free CLI via npx @babelize/cli.
- Target persona: Developers and small product teams shipping web/mobile apps who want to go multi
- Audience type: [B2B](https://trustmrr.com/search?targetAudience=B2B)
- Team size: 2–5 people
- Funding: Bootstrapped
- Estimated user count: 50
- Additional info: AST-based i18n automation: extracts strings, generates keys, translates, and injects code for React, Next.js, Vue and React Native, then opens a PR. Includes dashboard, Rust translator, CLI, SDK, MCP server and build plugins (all on npm). Pre-revenue. Sale includes code, domain, npm and GitHub orgs,

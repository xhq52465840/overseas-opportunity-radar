## Startup Insights

- Value proposition: See and answer your AI coding agents from any browser tab: approve permission prompts and reply without switching to the terminal.
- Problem solved: Coding agents sit waiting on a permission prompt or a reply while you're reading docs in the browser, and with several terminals open you can't tell which one needs you.
- Pricing model: $6 one-time during the early-bird offer (regular $25; ₹499 / ₹2,199 in India). Lifetime updates, one license for up to 3 browsers, 7-day refund.
- Target persona: Developers running Claude Code, OpenCode or omp, especially several sessions at
- Audience type: [Both](https://trustmrr.com/search?targetAudience=Both)
- Team size: 1 person
- Funding: Bootstrapped
- Estimated user count: 0
- Additional info: Local helper on 127.0.0.1 plus a Chrome extension; code and prompts never leave your machine. 8 named pets plus your own cat from a photo. Desktop notifications with Allow and Deny. Install with npx getagentpets init.

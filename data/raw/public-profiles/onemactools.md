## Startup Insights

- Value proposition: 151 Mac tools in one private app: everything runs on your Mac, nothing is uploaded, and you pay once.
- Problem solved: Replaces a pile of single-purpose apps, subscriptions and sketchy upload websites for everyday file jobs, without sending your files anywhere.
- Pricing model: One-time licence: $19 (1 Mac), $39 (5 Macs), $79 (15 Macs), $99 (25 Macs). Launch offer: $9 for the first 100, then $15.
- Target persona: Mac users who work with files every day: creators, freelancers, students, office
- Audience type: [Both](https://trustmrr.com/search?targetAudience=Both)
- Team size: 1 person
- Funding: Bootstrapped
- Estimated user count: 0
- Additional info: Native Swift app for macOS 26+. Works from Finder Quick Actions, Shortcuts, the menu bar and Watch Folders, plus an MCP server so AI agents can run tools with your approval. Free updates for version 1, 14-day money-back guarantee.

## Startup Insights

- Value proposition: Backtest any Trade-Ideas setup against 454k+ historical alerts since 2019 — then watch matching names live, or query the same engine in Telegram, REST API, CLI, or Claude MCP.
- Problem solved: Traders take alerts on gut feel because Trade-Ideas history is capped at 90 days. FILTRIX shows whether a setup has historically closed green, with sample size, before capital is at risk.
- Pricing model: Free: 3 backtests/day · 100-row CSV · Telegram 3 queries/day (10 if the Filtrix account is linked). Pro: $29/mo or $99 lifetime — unlimited backtests,
- Target persona: Day traders who use Trade-Ideas or similar scanners, plus developers and AI agen
- Audience type: [B2C](https://trustmrr.com/search?targetAudience=B2C)
- Team size: 2–5 people
- Funding: Bootstrapped
- Estimated user count: 57
- Additional info: Product: Context backtester, Execution analysis, KYT (4,400+ tickers), Live Scanner (Pro, beta), Telegram agent (@FILTRIX_BOT), Play simulator, Wall, weekly guide, SEO stock/sector pages. Agent stack: REST API, filtrix-cli, filtrix-mcp. Data: 454,449 Trade-Ideas alerts (2019-09-19 → present), 125M+

## Startup Insights

- Value proposition: One API key for public Instagram and TikTok data: profiles, posts, reels, comments, hashtags and stories as clean JSON, plus an MCP server for AI agents.
- Problem solved: Scraping Instagram and Tiktok yourself means proxies, logins, 429s and breakage every time Instagram changes. GramScraper handles all of that so you just make a REST call.
- Pricing model: Free: 100 credits on signup. Standard: $45 for 25,000 credits. Business: $300 for 320,000 credits. One-time purchases, no subscription, credits never
- Target persona: Developers
- Audience type: [B2B](https://trustmrr.com/search?targetAudience=B2B)
- Funding: Bootstrapped
- Estimated user count: 0
- Additional info: 91+ endpoints across Instagram and TikTok. Official MCP server for Claude and other AI agents. Free API playground, no signup needed. 11 free creator tools (engagement rate, earnings, profile viewer).
